# Качение шара по наклонной плоскости с трением

Проект моделирует движение однородного сплошного шара по наклонной плоскости с сухим трением: качение без проскальзывания, движение с проскальзыванием и переход между этими режимами. Анимация сопровождается графиками энергетического баланса и изменения момента импульса.

[Отчёт по результатам моделирования](docs/report.md).

## Запуск

Команды выполняются из корня проекта:

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python3 src/main.py
```

## Сценарии

- `rolling` — качение без проскальзывания (по умолчанию).
- `slipping` — движение с проскальзыванием.
- `slip_to_roll` — переход от проскальзывания к чистому качению.
- `custom` — сценарий с пользовательскими параметрами.

Примеры запуска:

```bash
python3 src/main.py slip_to_roll
python3 src/main.py custom --angle 20 --mu 0.05 --v0 2
```

Параметры можно изменять у любого сценария. Полный список параметров: `python3 src/main.py --help`.
